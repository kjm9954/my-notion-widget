The six cream/olive widgets use the same same-origin font URL and shared
`../../../pretendard.css`. No installed-font lookup or third-party CDN is required.
The font is not subsetted to the preview text, so newly typed Korean text uses
the same bundled font. Normal browser caching can reuse it across the six pages.

Webfonts require a successful initial font download. If webfonts are disabled or
the request fails, readable system fallbacks remain available; rendering cannot
be guaranteed in those conditions. Operating-system rasterization and glyphs
outside Pretendard's character coverage can still differ.
